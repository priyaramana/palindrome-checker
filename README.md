
# Palindrome Checker

A responsive web application that checks whether a word, number, or sentence is a palindrome.

## Features
- Check whether text is a palindrome.
- Case-insensitive comparison.
- Ignores spaces and special characters.
- Displays the result instantly.
- Clear button to reset the input.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Concepts Practiced
- DOM Manipulation
- Event Listeners
- Arrays and Strings
- Loops and Conditions
- String Methods
- Regular Expressions

## How to Run
1. Clone this repository.
2. Open `index.html` in your browser.
3. Enter a word or sentence.
4. Click Check to see the result.

## Example

Input: A man, a plan, a canal: Panama

Output: Palindrome
